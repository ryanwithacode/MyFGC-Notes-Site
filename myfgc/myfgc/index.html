Welcome to MyFGC

Notes for the games you play. Start with a note, or make a folder first.

Notes save in this browser automatically. A save file keeps a JSON copy on your computer too (Chrome and Edge).

You can also drop files here or paste an image into the note. Files stay in this browser (Export JSON saves your text and embedded links, not the files). Embeds need an internet connection and the app opened from a web address, such as Live Server or GitHub Pages.
